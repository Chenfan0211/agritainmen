# 数字供应链平台 · 功能清单

> 变更日期：2026-10-11
> 本文档按应用端归组，以表格形式逐模块描述平台功能。

---

## 端概览

| 端 | 包名 | 构建目标 | 定位 |
|---|---|---|---|
| admin | `@agritainment/admin` | H5（PC 工作台） | 运营管理后台（中控台） |
| user | `@agritainment/user` | 微信小程序 | 用户端分销商城（快递直发） |
| store | `@agritainment/store` | 微信小程序 | 门店订货商城（供货价直采） |
| supplier | `@agritainment/supplier` | 微信小程序 | 供应商配送工作台（供应商/司机双角色） |

共享包：`packages/shared`（业务类型 / 演示数据 / 仓储）、`packages/ui`（设计 token）、`packages/tencent-map-gateway`（腾讯地图网关）。

---

## 一、admin —— 运营管理后台（中控台）

管理后台按侧栏分为四大分区、17 个菜单模块。

### 平台总览

#### 数据看板

| 二级功能 | 功能说明 |
|---|---|
| 核心经营指标 | 汇总交易额、订单量、门店数、商品数、供应商数、用户数 |
| 交易趋势分析 | 按日 / 周 / 月查看交易额与订单量趋势，支持走势对比 |
| 品类销售分析 | 各品类的销售额、订单量、销量及占比统计 |
| 热销商品排行 | 按销量或销售额展示热销排行，辅助选品与补货 |
| 实时待办中心 | 集中展示待审供应商、待审商品、待发货订单、待处理售后 |

#### 经营报表

| 二级功能 | 功能说明 |
|---|---|
| 报表查询 | 按时间（日）、门店、供应商、品类四个维度筛选 |
| 去重摘要 | 对多维度数据进行去重与汇总摘要 |
| 数据导出 | 支持 CSV 导出 |

### 供应链

#### 预约管理

| 二级功能 | 功能说明 |
|---|---|
| 预约列表 | 按状态（待确认 / 已确认 / 已完成 / 已取消）筛选全部门店预约 |
| 预约详情 | 查看预订内容、时间、人数、金额与当前状态 |

#### 供应商管理

| 二级功能 | 功能说明 |
|---|---|
| 供应商邀请入驻 | 录入名称、经营品类、地区、联系人信息，发起合作邀请 |
| 供应商资料维护 | 维护企业信息、联系人、联系电话、经营区域、供货品类 |
| 供应商资质审核 | 审核营业执照、经营许可、资质有效期及证明材料 |
| 合作状态管理 | 管理待审核 / 合作中 / 已停用等状态 |
| 供应品类管理 | 配置供应商可供商品分类、品牌、服务区域 |
| 供应商结算 | 统计应结货款、退款扣减、结算状态与历史结算记录 |

#### 商品库管理

| 二级功能 | 功能说明 |
|---|---|
| 双目录维护 | 门店订货商品、用户商城商品分开维护 |
| 商品基础信息 | 名称、分类、供应商、标签、规格、详情、配送方式 |
| 商品图片素材 | 主图、轮播图、规格图、介绍素材 |
| SKU 规格管理 | 多规格配置、规格编码、规格价格、独立库存 |
| 库存管理 | 查看与调整库存、库存预警、库存变化记录 |
| 商品审核 | 供应商提交 / 门店自营商品审核、驳回、重新提交 |
| 商品上下架 | 控制商品销售状态及各业务端展示范围 |
| 分类筛选 | 按「全部商品 / 门店商品 / 直播平台商品」统一筛选 |

#### 品类管理

| 二级功能 | 功能说明 |
|---|---|
| 品类维护 | 商品品类与供应品类的新增、修改、排序、停用 |
| 品类图片 | 品类图标 / 分类图维护 |

#### 旅游线路

| 二级功能 | 功能说明 |
|---|---|
| 线路展示 | 乡村旅游线路、行程内容、关联门店、线路特色 |
| 线路报名 | 查看已报名线路、报名信息管理 |

#### 价格体系

| 二级功能 | 功能说明 |
|---|---|
| 集采价格 | 平台集中采购价与建议零售价维护 |
| 阶梯价格 | 按采购数量分档，达到条件自动匹配 |
| 区域价格 | 按城市、区域或服务范围配置差异化价格 |
| 会员价格 | 按会员等级配置专属价格与优惠规则 |
| 分销价格 | 基础价、一级分佣、二级分佣、用户端展示价 |

#### 订单履约

| 二级功能 | 功能说明 |
|---|---|
| 订单统一查询 | 门店采购订单、用户商城订单、各供应商子订单 |
| 多供应商拆单 | 按商品供应商拆分为独立履约子订单 |
| 订单状态管理 | 待支付 / 待接单 / 待发货 / 配送中 / 已收货 / 已取消 |
| 批量发货 | 多笔符合条件的订单统一发货 |
| 物流跟踪 | 配送方式、承运信息、运单号、物流轨迹、签收结果 |

#### 售后结算

| 二级功能 | 功能说明 |
|---|---|
| 售后工单 | 售后申请处理 |
| 退款与退货 | 仅退款、退货退款、退款失败重试、退货物流 |
| 售后统计 | 售后数量、退款金额、售后率、供应商责任 |

#### 农家乐管理

| 二级功能 | 功能说明 |
|---|---|
| 门店入驻管理 | 门店名称、地区、地址、联系人、营业信息 |
| 门店经营资料 | 门店标签、评分、人均消费、展示图片、经营状态 |
| 门店账号管理 | 创建店长 / 店员账号、启停状态、所属门店 |
| 门店推广权限 | 控制店员推广资格及门店推广业务权限 |

#### 推客管理

| 二级功能 | 功能说明 |
|---|---|
| 推客资源管理 | 推客 / 达人 / 主播资料、等级、类型、合作状态 |
| 推广效果统计 | 分享次数、访问用户、绑定用户、成交订单、推广贡献 |

#### 佣金结算

| 二级功能 | 功能说明 |
|---|---|
| 佣金结算 | 推客佣金汇总、待结算 / 可结算 / 已结算记录 |
| 提现审核 | 推客与分销商提现申请审核（通过 / 驳回、备注、余额恢复） |
| 供应商结算 | 供应商货款结算记录 |
| 佣金规则 | 全局推客 / 店员分成比例、商品级覆盖 |
| 消费分成 | 用户绑定消费分成记录 |

### 系统

#### 字典数据

| 二级功能 | 功能说明 |
|---|---|
| 业务字典 | 城市、售后原因、业务状态等统一字典维护 |
| 字典项 | 标签、排序、色调、图片 |

#### 操作日志

| 二级功能 | 功能说明 |
|---|---|
| 登录与操作记录 | 用户登录、关键业务操作、权限变更的记录查询 |
| 日志筛选 | 按操作人、角色、模块、结果（成功 / 失败）筛选 |

#### 角色管理

| 二级功能 | 功能说明 |
|---|---|
| 角色配置 | 角色菜单权限（17 个菜单键）+ 操作权限（细粒度动作）配置 |
| 启停管理 | 角色启用 / 停用 |

#### 账号管理

| 二级功能 | 功能说明 |
|---|---|
| 后台账号 | 账号创建、角色分配、启停状态管理 |

## 二、user —— 用户端分销商城

用户端 C 端分销商城，四个主 Tab：首页 / 分类 / 购物车 / 我的，商品统一快递直发。

### 登录与身份

| 二级功能 | 功能说明 |
|---|---|
| 微信授权登录 | 微信授权完成登录、身份识别与账号建立 |
| 分销身份 | 普通用户 / 一级分销商 / 二级分销商，按身份展示差异化价格 |
| 身份切换 | 演示环境可切换分销等级查看对应价格 |

### 商品商城（首页 / 分类）

| 二级功能 | 功能说明 |
|---|---|
| 商品分类 | 按土特产、粮油、茶饮等分类浏览快递直发商品 |
| 商品搜索 | 按商品名、供应商、标签搜索 |
| 商品详情 | 图片、供应商、标签、规格、库存、配送说明 |
| 分销价格 | 按用户身份展示基础价及对应分销价 |
| 产地直播 | 直播平台商品入口与套餐购买 |

### 购物车

| 二级功能 | 功能说明 |
|---|---|
| 加入购物车 | 选择商品规格及数量加入 |
| 购物车管理 | 数量调整、删除、失效提示、库存校验、金额计算 |
| 配送方式切换 | 快递直发 / 到店自提商品分组结算 |

### 收货地址

| 二级功能 | 功能说明 |
|---|---|
| 地址维护 | 新增、编辑、删除收货人、手机号、地区、详细地址 |
| 默认地址 | 设置默认地址、结算时切换 |

### 订单交易

| 二级功能 | 功能说明 |
|---|---|
| 提交订单 | 确认商品、地址、配送方式、金额、备注后提交主订单 |
| 多供应商拆单 | 按商品供应商拆分为多个独立子订单 |
| 在线支付 | 模拟支付 |
| 订单状态 | 待支付 / 备货 / 部分发货 / 已发货 / 部分收货 / 已收货 / 售后 |
| 取消订单 | 待支付或未履约订单取消，库存释放 |

### 履约售后

| 二级功能 | 功能说明 |
|---|---|
| 子订单物流 | 按供应商子订单查看承运信息、运单号、物流轨迹 |
| 确认收货 | 已送达子订单确认收货，佣金到账 |
| 按子订单售后 | 指定子订单退款、退货、质量问题售后 |

### 推广佣金

| 二级功能 | 功能说明 |
|---|---|
| 分销关系绑定 | 推广来源、上级分销关系、关系锁定 |
| 佣金明细 | 一级 / 二级分佣记录，可提现 / 待结算 / 已提现 / 已冲正 |
| 佣金提现 | 汇总可提现佣金提交提现申请 |

### 分销经营（我的）

| 二级功能 | 功能说明 |
|---|---|
| 我的收入 | 可提现金额、累计收入、已结算、待结算、已提现 |
| 我的粉丝 | 直属粉丝、团队分销商 |
| 团队订单 | 个人订单、团队订单 |
| 团队业绩 | 累计团队业绩、有效订单、团队分销商 |

## 三、store —— 门店订货商城

门店以供货价向供应链中台直采下单，四个主 Tab：首页 / 分类 / 进货单 / 我的。不同业务员对应不同购买价。

### 登录与身份

| 二级功能 | 功能说明 |
|---|---|
| 密码登录 | 手机号密码登录 |
| 验证码登录 | 验证码登录（页面自动填充，一键登录） |
| 业务员角色 | 门店以业务员身份登录，不同业务员对应不同供货价 |

### 商品采购（首页 / 分类）

| 二级功能 | 功能说明 |
|---|---|
| 供货商品目录 | 平台供应商品的分类、名称、图片、供货方、可采购状态 |
| 商品搜索 | 按商品名 / 供应商关键词搜索 |
| 分类浏览 | 按品类侧栏浏览（所有商品 + 各品类） |
| 商品详情 | 规格、供货价、建议零售价、库存、销量、介绍 |
| 业务员差异价 | 同一商品按业务员身份展示差异化供货价 |
| 多规格采购 | 选择不同规格及数量加入进货车 |
| 热销常订 | 按进货次数展示常订商品 |

### 进货车（进货单）

| 二级功能 | 功能说明 |
|---|---|
| 进货车管理 | 数量增减、删除、规格区分、库存校验、金额汇总 |
| 缺货提示 | 无库存商品的不可用标记 |
| 采购备注 | 包装、配送及采购要求 |

### 采购订单（我的 - 订单）

| 二级功能 | 功能说明 |
|---|---|
| 提交采购订单 | 根据采购商品生成订单，分配对应供应商 |
| 订单分类 | 待接单 / 待发货 / 已发货 / 配送中 / 已收货 / 已完成 |
| 订单详情 | 商品、数量、金额、节省金额、备注、履约进度 |
| 物流轨迹 | 接单 / 发货 / 配送 / 签收 / 完成节点 |
| 确认收货 | 配送完成确认收货并记录签收时间 |
| 取消订单 | 允许状态下取消 |
| 采购售后 | 退款、退货、质量问题售后 |
| 再次采购 | 历史订单商品快速加入进货车 |
| 采购概览 | 月采购额、采购订单数、待收货数量、节省金额 |

## 四、supplier —— 供应商配送工作台

供应商与司机双角色配送履约，按 `supplierId` 隔离数据。

### 账号与权限

| 二级功能 | 功能说明 |
|---|---|
| 双角色登录 | 供应商账号与司机账号分别登录对应工作台 |
| 数据隔离 | 供应商只能查看归属本供应商的订单、司机、履约数据 |
| 重置演示数据 | 一键清空本地订单 / 司机 / 交接数据并重播种子 |

### 供应商工作台

| 二级功能 | 功能说明 |
|---|---|
| 订单指标 | 待接单、待发货、配送中、已完成、缺货订单数量 |
| 履约概览 | 订单金额、配送任务、司机状态、异常待办 |
| 身份展示 | 供应商编号 / 登录账号展示 |

### 订单管理

| 二级功能 | 功能说明 |
|---|---|
| 多来源订单 | 统一承接门店采购订单与用户商城快递订单 |
| 订单查询 | 按订单号、门店、收货人、关键词查询 |
| 状态与缺货筛选 | 按履约状态或缺货筛选 |
| 接单 / 批量接单 | 单笔 / 批量确认待接订单 |
| 订单详情 | 商品、数量、金额、司机 / 运单 / 配送日期信息 |

### 发货配送

| 二级功能 | 功能说明 |
|---|---|
| 快递直发 | 选择快递配送，物流 Provider 创建运单返回运单号 |
| 司机配送 | 选择可用司机执行门店配送任务 |
| 指派改派 | 在允许履约节点指派 / 更换司机 |
| 快递签收 | 接收物流签收结果更新订单状态 |

### 缺货处理

| 二级功能 | 功能说明 |
|---|---|
| 缺货登记 | 按商品规格登记订购数量、实际数量、缺货数量 |
| 缺货明细 | 缺货商品、数量、处理状态、相关记录 |
| 补发处理 | 对缺货商品创建补发安排 |

### 交接管理

| 二级功能 | 功能说明 |
|---|---|
| 出库交接 | 供应商出库、司机领货、实际数量、缺货、交接时间 |
| 交接单审核 | 司机提交后供应商「修改并确认」或「驳回修改」、填写驳回原因 |
| 到店交接 | 司机到店登记交接结果、备注、完成时间 |
| 交接日志 | 按订单 / 司机查看出库、领货、到店及异常交接记录 |

### 配送线路

| 二级功能 | 功能说明 |
|---|---|
| 命名线路 | 新建 / 保存线路模板（如东线 / 西线），固定门店顺序 |
| 线路司机 | 为线路指定司机 |
| 路线预览 | 生成配送路线预览 |
| 发布线路 | 为指定日期发布配送任务 |
| 按今天补生成 | 按当天门店订单补生成配送任务 |

### 仓点设置

| 二级功能 | 功能说明 |
|---|---|
| 仓点信息 | 供应商仓点 / 联系人维护 |

### 结算账单

| 二级功能 | 功能说明 |
|---|---|
| 结算记录 | 周期、关联订单数、结算金额查看 |

### 司机管理

| 二级功能 | 功能说明 |
|---|---|
| 司机账号 | 新增司机，姓名、手机号、登录账号、初始密码 |
| 司机资料与状态 | 编辑资料、启停账号、当前任务状态 |
| 司机密码重置 | 重置登录密码 |

### 司机任务（司机角色）

| 二级功能 | 功能说明 |
|---|---|
| 今日配送 | 待领货、配送中、待交接任务 |
| 配送数据 | 按日期查看线路数量、配送门店、配送件数、缺货件数、线路完成率 |
| 历史任务 | 历史配送订单、完成时间、交接结果 |
| 我的交接 | 当前司机的出库 / 到店交接记录 |
| 所属供应商展示 | 所属供应商 / 仓点展示 |
