# 移动商城与分销运营改版实施计划

## 目标

- 用户端改为四栏移动商城，并为分销商提供可实时计算的运营中心与商品分享。
- 门店端移除商品上架、下架及库存编辑，只保留渠道商品浏览与采购。
- 供应商端重做移动端商品工作区，补齐商品发布、图片、标签和多 SKU 编辑能力。

## 实施步骤

1. 为用户端新增运营数据投影纯函数及单元测试，固化个人/团队订单与业绩口径。
2. 调整用户端页面、路由和启动参数，完成首页、分类、购物车、我的及四个运营详情页。
3. 增加门店端能力边界测试，删除库存编辑和上下架入口与页面状态。
4. 扩展供应商商品契约测试并重做移动端商品列表和发布编辑表单。
5. 运行全量测试、类型检查、H5/微信小程序构建，并对典型移动视口做页面检查。

## 验收标准

- 用户端底栏为“首页 / 分类 / 购物车 / 我的”，普通用户购买、分销商分享逻辑清晰。
- 分销商四个运营入口只展示真实计算数据；普通用户不显示运营宫格。
- 门店端不存在库存保存、上架或下架能力。
- 供应商可新增/编辑商品与多 SKU；资料变更走审核，审核通过商品可自行上下架和调库存。
- 三端在 375、390、430 像素宽度下无横向溢出、关键控件遮挡或底部安全区问题。
