# 中选科技数字供应链平台前端

基于 Uni-app、Vue 3、TypeScript 和 Pinia 的多端前端演示工程。项目不包含后端服务，业务数据和状态流转均在本地完成。

本仓库是平台工程的四端裁剪副本，只保留运营后台、供应商端、门店订货端和用户端；裁剪范围、来源提交与"恢复/新增一端"的操作规程见 [`MIGRATION-NOTES.md`](MIGRATION-NOTES.md)。

## 应用

- `apps/admin`：中选科技供应链管理后台（运营后台），仅构建 H5。
- `apps/store`：中选科技门店订货商城（门店订货端），门店以供货价向中选科技供应链中台直采下单并查看订单，构建 H5 和微信小程序。
- `apps/user`：中选科技用户端 C 端分销商城（H5 + 微信小程序），浏览快递直发商品、按普通/一级/二级分销身份显示价格、购物车结算、查看多供应商子订单和佣金。
- `apps/supplier`：中选科技供应商配送工作台（微信小程序为主，H5 用于开发预览和同源联调），供应商按 `supplierId` 隔离订单；供应商处理 C 端商城快递订单和传统门店进货单，司机仅处理门店配送任务，缺货自动统计。
- `packages/shared`：公共业务类型、演示数据和纯函数。
- `packages/ui`：共享设计令牌、移动端主题、业务图片组件与媒体运行时。
- `packages/tencent-map-gateway`：腾讯地图 WebService 同源网关，供运营后台地址解析和供应商端线路规划使用。

## 开发

```bash
pnpm install
pnpm dev:admin
pnpm dev:store
pnpm dev:user
pnpm dev:supplier
```

默认开发地址由 Uni-app 输出。各应用请分别启动，避免端口冲突。

## 验证

```bash
pnpm test
pnpm test:e2e
pnpm typecheck
pnpm build
```

`pnpm build` 会依次构建运营后台 H5、门店订货端 H5/微信小程序、供应商端 H5/微信小程序（H5 用于开发预览）和用户端 H5/微信小程序。

预览端口：admin 8791、store 8795、user 8797、supplier 8798（见 `scripts/serve-dist.mjs`）。四端同源 H5 联调使用 `pnpm build:single-origin`、`node scripts/serve-single-origin.mjs` 和 `pnpm check:single-origin`，统一从 `http://127.0.0.1:8780` 下的 `/admin/`、`/store/`、`/user/`、`/supplier/` 路径访问。生产部署通过 `VITE_PORTAL_ORIGIN` 注入真实域名，业务代码不会生成本机地址。

运营后台地址解析和供应商端线路规划固定调用同源 `/api/tencent-map/geocode`。腾讯 WebService Key 与 Secret 仅配置在 Node 网关环境变量中，不会进入前端构建产物。详细配置和 Nginx 反代示例见 [`docs/tencent-map.md`](docs/tencent-map.md)。

同源构建会把静态资源重写为 `/{app}/static/*`，避免四个应用的同名图片互相覆盖。完整目录、数据键和联调流程见 [`docs/integration.md`](docs/integration.md)。
首次执行端到端测试前运行 `pnpm exec playwright install chromium` 安装测试浏览器。

## 用户端商城与分销

- 中选科技用户端（apps/user）：商城是主入口，商品目录独立于门店订货商品，所有商品统一快递配送。普通用户、一级分销商、二级分销商分别按基础价、基础价加一级分佣、基础价加一级和二级分佣显示价格。
- 管理端商品库可切换“门店订货商品 / C 端商城商品”，C 端商品独立维护基础价、一级分佣、二级分佣、库存和上下架状态，固定快递配送。
- 用户端订单使用前端 mock/localStorage 完成购物车、地址、多供应商拆单和模拟支付；支付后按供应商生成稳定履约订单，由供应商端接单、快递发货并写回物流，用户端只查看物流、确认收货和发起售后，不接真实支付和后端接口。
- H5 同源部署支持管理端、门店订货端、用户端和供应商端共享 localStorage 联调，包括供应商账号创建、换号和改密；演示密码以明文保存在浏览器本地存储中。微信小程序跨应用不能依赖 localStorage，只通过跳转参数传递推广信息，生产环境的供应商账号必须改为服务端哈希密码与鉴权，并通过后端或云开发数据库实现跨应用同步。
- 用户绑定与消费分成：分销关系与佣金记录仍由用户端和运营后台读写；中控台（admin）可设置全局分成比例并查看分成记录。


## 商品标签与定价模型

- 管理后台商品库按“全部商品 / 门店商品 / 直播平台商品”统一筛选管理；门店商品面向中选科技农家乐门店端商城，直播平台商品仅展示在用户商城。
- 商品支持“快递直发”共享标签：用户商城商品固定快递配送；门店商品勾选后结算可选“快递配送（填收货地址）”或“到店自提”，快递单进入供应商履约链路并回写物流。
- 用户商城商品按 SKU 固定加价：基础价 + 一级加价 + 二级加价，按用户等级展示价格（内部结算字段保留分佣语义）。
- 门店商品按零售价比例分佣：推客/店员比例可在后台配置，支持商品级覆盖，剩余为门店与平台毛利。
- 套餐券与服务类商品固定到店核销，不支持快递直发。
